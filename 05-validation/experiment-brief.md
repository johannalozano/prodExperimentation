# The Validation · FinWise

> Module 5 · Experimentation Methods. The experiment brief that tests the bet.

## Method

**Method:** A/B Test

**Why:** A standard A/B test is the simplest and most appropriate method because FinWise is comparing the current trial experience against one value-focused variant. It provides a clear causal comparison, is easy to interpret, and avoids unnecessary complexity since there are no multiple competing variants, geographic constraints, or strong time-based effects to account for.

_____

## Hypothesis + primary metric

If we replace the current trial experience with a value-focused experience that guides users to import data, reach their first modeling output, and understand a meaningful financial insight, then trial-to-paid conversion will increase because more users will experience FinWise’s core value before deciding whether to pay.

**Primary metric:** Trial-to-paid conversion rate, target: increase by at least **4 percentage points, from ~2% to 6%**

_Experiment: Value Realization Trial Experience Test, objective: increase trial-to-paid conversion by helping new trial users reach a meaningful financial insight faster and more consistently._

_Testing a value-focused trial experience on brand-new FinWise trial users. Current experience: new trial users go through the existing FinWise experience and may access features such as data import and financial modeling, but there is no dedicated flow designed to help them reach a clear financial insight as quickly as possible._

_Predicted outcome: the value-focused trial experience will help more users reach a meaningful financial insight during the trial, increasing trial-to-paid conversion from ~2% to at least 6%. If successful: roll out the value-focused experience to all new trial users, then optimize the parts of the flow that most affect activation, such as time-to-Aha, data import completion, and the first modeling insight. If unsuccessful: review the leading indicators to determine whether users reached the Aha moment faster or more often; if they did but conversion did not improve, revise the hypothesis that value realization is the main conversion constraint and investigate other factors such as pricing, product depth, or the pay prompt experience._

_____

## Guardrail + read date

- **Guardrail:** Early trial disengagement / day-1 drop-off must not increase relative to the control group.
- **Read date:** 3 weeks after launch, no earlier, and only once the minimum required sample size has been reached.
